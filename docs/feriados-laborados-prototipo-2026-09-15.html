Actas firmadas

El acuerdo se registra en «Registrar»; acá vive el papel firmado que lo respalda. Una acta cubre a todas las personas de ese acuerdo. Cada referencia solo se puede elegir de una lista — ya no se tipea libre — para que no queden actas huérfanas por una letra distinta.
