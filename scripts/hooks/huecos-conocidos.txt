# Huecos de numeración ya explicados.
#
# `numeracion.sh` avisa cuando falta un número en supabase/migrations. Los que
# están acá ya se investigaron y no van a volver: si siguieran avisando en cada
# push, el aviso se leería siempre igual y siempre en falso, y el día que
# apareciera un hueco de verdad nadie lo miraría.
#
# PARA AGREGAR UNO: una línea con el número y por qué falta. Nada más — el
# script no tiene que tocarse. Y escribir la razón es el punto: un número suelto
# acá dentro solo mueve el problema de sitio.
#
# ANTES DE AGREGAR UNO, ASEGURATE DE QUE DE VERDAD ESTÁ EXPLICADO. Un hueco
# también puede ser algo aplicado en producción que nunca llegó al repo, que es
# lo peor que puede pasarle a este sistema. La forma de descartarlo es correr
# la consulta que genera `./scripts/que-falta-pegar.sh`, corrida en producción:
# si el número aparece como «SOBRA LA FILA», no es un hueco explicado — es una
# migración perdida, y hay que recuperar su contenido antes de silenciarla.
#
# SALVO UN CASO, que lleva marca propia: la fila está en producción pero su
# contenido quedó SUPERADO por migraciones que sí están guardadas, y recuperar
# el archivo haría daño (ver la 0393, abajo). Esa línea se escribe
#
#   0393  [sobra la fila: <nombre exacto en migraciones_aplicadas>] <razón>
#
# y `que-falta-pegar.sh` la muestra como «ya explicada» en vez de gritar «MIRA
# ARRIBA». El nombre va porque es lo que prueba que la fila es LA que se
# investigó: si otra migración se pega mañana con el mismo número, el nombre
# cambia y el aviso vuelve solo. Sin marca, el aviso sigue — que es lo seguro.
